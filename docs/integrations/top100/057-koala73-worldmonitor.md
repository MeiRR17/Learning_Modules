# תוכנית מימוש 57: koala73/worldmonitor

**בעלים:** MeiRR17/Learning_Modules | **עדיפות:** P2 | **החלטה:** REFERENCE | **מקור:** https://github.com/koala73/worldmonitor

## נחיצות
Study geopolitical monitoring UI for independent evidence-led media design.
המאגר Learning_Modules הוא מאגר ציבורי של כלי מדיה ולמידה. אין לפרסם בו אוטומטית תוכן חדשותי, נתוני מקורות שנאספו בזכויות מוגבלות או תוצרי מדיה שאינם בבעלותנו.

## ארכיטקטורה ותכנון
Public-source event summaries and canonical links -> human-reviewed situation board.
לשמור מצביעים וקישורי מקור, תאריכי אירוע ופרסום בנפרד, ולעבור דרך תהליך fact checking ובדיקת זכויות לפני תוצר כלשהו.

## תוכנית פיתוח
1. **0.1 — ביקורת צורך ורישוי:** לבחון את ממשקי הפרויקט, הצורך המעשי בדשבורד מחקר ואת רישיון AGPL-3.0. לשמור החלטת אימוץ בתור reference בלבד עד חוות דעת על מגבלות השימוש.
2. **0.2 — השוואת עיצוב ללא העתקת קוד:** לבנות באופן עצמאי רשימת events/locations/sources מקורית על סמך נתוני דוגמה, מבלי להעתיק HTML, איורים או נתונים מוגנים מ־upstream.
3. **0.3 — פיילוט מקורות:** Compare two historical events for source traceability, time zones and licensing. לתעד שגיאות זמן, רלוונטיות, שיעור מקרים ללא מקור וקונפליקטים בין מקורות.
4. **0.4 — שער פרסום:** תהליך Human-in-the-loop, אישור מדיה, תיעוד תמיכה בממצאים והפרדה ברורה בין דיווח, דעה והשערה.
5. **0.5 — בדיקות ו־rollback:** לוודא ערכי זמן, עברית, ציון מקורות ואפשרות לבטל פרסום לפני/אחרי ניסיון ללא מחיקת ראיות; אין הפעלה אוטומטית.
6. **1.0 — פרודקשן מותנה:** רק אם יש רישוי, תהליך בקרת איכות, זכויות הפצה ומדיניות פרטיות ברורים. אין תלות חובה במאגר החיצוני.

## מדדי קבלה
למדוד אחוז אירועים עם מקור מאומת, שיעור שגיאות זמן ותיאור, שיעור פריטי זכויות חסרים וזמן ממוצע לבדיקת אנוש. פיילוט נתונים סינתטיים לא נחשב למערכת חדשות אמיתית.

## החלטה וסיכונים
Use interface concepts only; no copying/reposting protected news or AGPL code.
AGPL-3.0, misinformation, safety and copyright.
ההמלצה היא **REFERENCE** — ללמוד מכווני עיצוב/אימות ולכתוב מימוש עצמאי בלבד. לא להטמיע שרת או קוד AGPL ללא בדיקת חובה משפטית.

## Definition of Done
מסמך זכויות, fixture מאושר, בדיקות תאריכים והפניות, ניתוח מקור מול תוצר, דוח פיילוט, שיטות התאוששות ו־PR נפרד עם ראיות. עד אז אין סימון installed/production.
